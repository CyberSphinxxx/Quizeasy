# Quizeasy

**Paste questions. Review the import. Start studying.**

Quizeasy is an open-source, local-first quiz maker and study app. Paste text that
already looks like question and answer pairs — your own notes, or output from
ChatGPT, Gemini, Claude, or any other tool — review exactly what was understood,
then study the same set as flashcards, multiple choice, identification, or a
mixed quiz.

No account. No backend. No telemetry. Your sets stay in your browser.

## Features

- **Forgiving text import.** Recognizes labelled (`Q:`/`A:`/`W:`/`E:`/`T:`),
  numbered-pair, and pipe-delimited text, including Markdown cleanup and
  multi-line fields. Every entry is shown for review before anything is saved.
- **Inline correction.** Fix or exclude individual entries in the preview; valid
  entries after a malformed one are still recovered.
- **One question bank, four study modes.** Flashcards, multiple choice,
  identification, and a mixed quiz built from the same data.
- **Honest multiple choice.** Wrong answers come from your `W:` lines or from
  other answers in the same set. Quizeasy never invents a distractor, never
  repeats the correct answer, and disables the mode for questions it cannot
  build honestly.
- **Tolerant identification.** Case, spacing, punctuation, and accepted variants
  are normalized without accepting clearly wrong answers.
- **Study and test modes.** Immediate feedback while learning, or delayed
  feedback with a score at the end.
- **Session options.** Question limit, shuffle questions, shuffle choices,
  filter by tag.
- **Results and retry.** Score breakdown, per-mode totals, a list of missed
  questions, and one-click retry of only the mistakes.
- **Portable data.** Export one set (`.quizeasy.json`), or export/restore a full
  backup (`quizeasy-backup.json`). Restoring merges — it never overwrites or
  wipes what you already have.
- **Works offline.** Installable PWA with a cached app shell; new versions are
  announced instead of force-reloading mid-session.
- **Keyboard friendly, accessible, responsive.** Primary flows work with a
  keyboard, correctness is never signalled by color alone, and mobile layouts
  are first-class.
- **AI guide, no API key.** Copyable prompts plus a workflow for using an
  external AI — accuracy caveat included.

## Why local-first?

Study material is personal. A quiz app should not need an account, a server, or a
subscription to do its job. Quizeasy keeps everything in IndexedDB on your device
and gives you plain JSON exports, so you own the data and can move it anywhere.

## Installation

```bash
git clone https://github.com/CyberSphinxxx/Quizeasy.git
cd Quizeasy
npm install
npm run dev
```

`npm run dev` starts Vite and prints a local URL. No backend, no API key, and no
cloud account are needed.

## Development

```bash
npm run dev            # dev server with hot reload
npm run typecheck      # tsc --noEmit
npm run lint           # ESLint
npm run lint:fix       # ESLint with --fix
npm run format         # Prettier write
npm run format:check   # Prettier check
```

The app is a single-page React app that uses **hash routing** (`/#/sets/…`), so a
production build can be served from any folder, subpath, or even `file://`
without server rewrites.

## Build

```bash
npm run build      # type-checks nothing extra; emits dist/ + the service worker
npm run preview    # serve dist/ locally
```

`vite build` also generates the PWA service worker and precache manifest through
`vite-plugin-pwa`. App icons are generated by `scripts/generate-icons.mjs`
(`node scripts/generate-icons.mjs`) and committed under `public/icons/`.

## Deployment

### Deploy to Vercel

Quizeasy is preconfigured for one-click deployment on [Vercel](https://vercel.com/) with [`vercel.json`](vercel.json):

1. **Via GitHub integration:**
   - Push your repository to GitHub.
   - Import the project on [Vercel](https://vercel.com/new).
   - The preset (`vite`), build command (`npm run build`), and output directory (`dist`) are automatically applied from [`vercel.json`](vercel.json).
   - Click **Deploy**.

2. **Via Vercel CLI:**
   ```bash
   npx vercel
   # Deploy to production:
   npx vercel --prod
   ```

The deployment configuration includes:

- SPA route rewrites for client-side routing.
- Immutable HTTP caching for hashed bundle assets in `/assets/`.
- Instant cache revalidation for the PWA service worker (`/sw.js`, `/workbox-*.js`), web manifest, and `index.html`.
- Strict security headers (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`).

## Import format

The parser is intentionally forgiving, but predictable. See
[`docs/06-IMPORT-PARSER-SPEC.md`](docs/06-IMPORT-PARSER-SPEC.md) for the full
specification.

### Canonical labelled format

```text
Q: What does CPU stand for?
A: Central Processing Unit
W: Central Program Unit
W: Computer Processing Utility
E: The CPU executes instructions and performs calculations.
T: hardware, computer
```

| Label | Aliases             | Meaning                   |
| ----- | ------------------- | ------------------------- |
| `Q:`  | `Question:`         | Prompt (required)         |
| `A:`  | `Answer:`           | Correct answer (required) |
| `W:`  | `Wrong:`, `Choice:` | A wrong choice            |
| `E:`  | `Explanation:`      | Shown with the answer     |
| `T:`  | `Tags:`             | Comma-separated tags      |

Labels are case-insensitive, may be wrapped in Markdown (`**Q:**`), may be
bulleted, and may be prefixed with numbering (`1. Q: …`). A second `A:` line for
the same question is treated as an accepted alternative answer.

### Numbered pairs

```text
1. What does RAM stand for?
Random Access Memory

2. What does CPU stand for?
Central Processing Unit
```

### Pipe delimited

```text
What does GPU stand for? | Graphics Processing Unit
What does HTML stand for? | HyperText Markup Language | Hyper Text Markup Language
```

The first field is the prompt, the second is the answer, and any remaining fields
are wrong choices.

### What the preview tells you

Every entry is classified as **valid**, **warning**, or **invalid**. Warnings
(for example a duplicate wrong choice, a wrong choice identical to the answer, an
unusually long field, or a likely duplicate question) do not block saving.
Invalid entries (a missing prompt or answer) must be fixed or excluded.

### Limits

| Limit                          | Value   |
| ------------------------------ | ------- |
| Characters per paste           | 500,000 |
| Questions per import           | 2,000   |
| Characters per field           | 4,000   |
| Length that triggers a warning | 600     |

## AI guide workflow

Quizeasy has no built-in AI and requires no API key. The **AI guide** screen in
the app provides copyable prompts that turn source material into Quizeasy-ready
text:

1. Open the AI guide and copy the prompt you want (simple Q&A, or MCQ-ready with
   wrong choices and explanations).
2. Paste it into your preferred AI tool along with your notes, slides, or a PDF.
3. Copy the answer, review it for accuracy, and paste it into Quizeasy's import
   screen.

AI output can be confidently wrong. Always review generated questions in the
import preview before studying them. [`docs/11-FUTURE-AI-INTEGRATION.md`](docs/11-FUTURE-AI-INTEGRATION.md)
describes the planned optional bring-your-own-key architecture; it is **not**
implemented in this release.

## Data privacy

- Sets, questions, sessions, attempts, and preferences are stored in this
  browser's **IndexedDB** only.
- There is no account, no server call for your content, and no analytics.
- Clearing site data removes everything, so export a backup first.
- Browser storage is not a secure secret store. Quizeasy never stores API keys
  and says so plainly before a future release lets you add one.

Report security concerns using [`SECURITY.md`](SECURITY.md), and never paste
private study material into a public issue.
